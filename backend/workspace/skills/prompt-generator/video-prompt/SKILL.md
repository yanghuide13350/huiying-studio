【2026-10-05 用户验收修订：跨镜动作只完成一次】
连续动作拆分先记录对象的实际状态：怀抱、双脚落地、坐在门槛等互不混用。上一镜已经落地，下一镜从落地状态发展；已经坐稳，下一镜保持坐姿。每个动作只归属其发生的时段，通用人物或比例约束不写尚未发生的抱起、放下、坐稳等动作，避免提前触发。改写现有成片继承真实末帧，核对手的位置、身体支撑点与姿态。行动目的用简短自然对白或叙述交代；原著未给出的制作对白标注改编，不冒称原文。

【2026-10-05 用户验收修订：群演密度与跨镜人流】
1. 分清“无新增命名角色”“无主角出场”和“画面无人”。人潮、集市、节庆、宴会、围观等剧情需要群演时，明确列出普通游人、家庭、孩童、摊主或围观者；主角角色绑定为空不等于场景无人，角色设定图只限定身份而不限定整幅画面的总人数。
2. 将热闹、人潮如织、拥挤等抽象词转成可见内容：前景经过的几组人、中景聚集的人群、远景连续头肩与身影、被遮住或露出的路面范围，配合牵孩子、看灯、挑货、侧身让路等群演动作。人数作为大致密度参考，不靠声音代替可见人群。中近景也保留边缘经过与背景群演，不因突出主角清空街道。
3. 同一时段相邻镜头的人群密度、流动方向、聚集位置和环境声连续。主街转到门边或侧巷可自然减少近处人群，但远处主街仍有对应人流；写清镜头位移。时间推移导致人潮渐稀时交代时段变化，区分散场与完全空街，避免每镜重新随机配置人数。
4. 保存前检查 description、video_prompt、出场人物、景别、尺度和声音的冲突：人潮如织不能同时要求空镜、无人物入画或画面无人；环境声有谈笑也须核对实际可见的街市状态。成片检查首中尾的人流与相邻接点，提示词和 completed 都不保证人群生成成功。

【2026-10-05 用户验收修订：紧凑剧情、运镜与转场吸引力】
1. 先按剧情推进单元决定视频数量，再分配时长。每段至少推进事件、人物关系或信息中的一项；同一空间内连续的翻书、听声、转头、起身、走到窗前可以合成一段，避免一个小动作单独耗一条视频。能在一段自然完成的动作不因景别改变额外拆段。对白和原著核心因果保留，心理叙述可简明转述并注明改写。
2. 每段指定吸引点及有动机的镜头变化：声响打断动作、沿人物视线揭示对象、从物件轻抬到反应、用动作结果引出下一事件。镜头服务叙事，静态等待仅留反应所需时长；不能用无关摇移、快速切镜或空景拖长。
3. 保存前按播放顺序把前段最后两秒与后段最初两秒成对写明。给出相同的角色位置、前后远近、手持物件、朝向、动作阶段和场景固定物；采用动作匹配、视线匹配或环境声桥。换室内外机位时用同一门窗与视线确认相邻空间，保留行走方向与轴线；不能仅凭两段同一个场景名认定连接。
4. 连续场景开场继承上一段收尾，不每段重新摆成人物面向镜头的展示构图。转身、放杯、放书、起身、走近或离开在画面内完成。提示词须逐对检查，改一段收尾要检查下一段开头；已有视频按实际生成末尾调整，文字中的预期位置不冒充成片事实。
5. 生成按剧情顺序逐段推进，检查真实首尾再决定后段参考与提示词。接口支持参考图时，可传入经过检查的前段末帧并核对任务参数；同一场景资产无法锁定机位和站位，写了“承接”也不能保证成片。提示词完成、视频生成完成、连续视听验收分别报告。

【2026-10-05 用户验收修订：镜间接点优先，作为拆分与提示词生成的共同规则】
1. 连续性以相邻成片的“上一段真实末帧 → 下一段真实首帧”逐对验收。除画面左中右，还须核对人物在谁的前面／后面、离镜头的远近、脚下路面或台阶、视线方向、身体朝向、抱孩子的一侧与道具所在手。单段好看不等于能连接；上一段已走到前面，下一段须从该位置开始，停步、回身或再走动要在画面内完成。
2. 优化已有镜头时先查看已接受视频的末尾，不按旧提示词猜收尾；保留已通过的前段。为每一接点记录具体末尾状态和后段开场状态。需要构图参考时使用经过检查的前段末帧作为实际传入的参考图片，并核对任务的参考图列表。参考图片只引导构图，不宣称具有接口未提供的首帧强制锁定能力。仅写 @场景名并不代表已传图，核对 scene_id 和实际生成参数。
3. 身高用可见比较写进视频提示词：成人站在同一片平整路面、离镜头距离接近，头部大小接近、头顶与肩线接近，特定人物仅高小半个头。米数、厘米数、height_cm 留作内部制作数据，不用来教视频模型。明确路面与台阶关系，避免一人站上台阶或靠近镜头而被误拍成巨人；跛态只改变姿态，不缩短骨架。景别变化只改变取景，人物位置和真实大小连续。
4. 原著没有口头回应的角色也须有可见的倾听与反馈，按原著情节用看一眼后移开视线、皱眉、护住孩子、转身欲走、迟疑或欲言又止表达。不凭空补对白；核对实际人物身份与原著回应顺序，不把甄士隐写成贾雨村。无声反应穿插在说话者对白过程中，空间与视线关系连续。
5. 成片依次检查首、中、尾，并将前段尾部与后段开头放在一起看；空间位置、前后深度、相对身高或表情动作跳变须修正后重生成。关键帧核对与完整视听验收分开报告；任务 completed、提示词保存成功或同一张场景图都不能替代接点验收。


【生成文本用具体正向画面描述】
旁白镜头的最终 video_prompt 用简短正向描述落实取景：例如“摄像机固定在人物正后方，中远景，人物全程背对镜头，画面只见后脑、肩背与道袍”，或“固定拍摄手部／道具／环境”。避免在生成文本中逐条罗列不回头、不转身、不拍正脸侧脸嘴部等否定约束；用要生成的画面替代反复提及要避开的动作与部位。领悟可用肩背放松、原地停顿表达；构图、动作、声音归属各写清一次，description 与 video_prompt 同步。完整保留旁白及其独立叙述者身份，角色现场对白仍按对白处理。

【旁白画面设计优先：避开人物面部】
用户实测仅写“闭口、不做口型”仍可能让旁白驱动入镜人物说话，后续优先从机位与取景规避，而非只追加嘴部禁止词。
1. 独立叙述者旁白或独白作为画外声音覆盖的时段，采用人物背影中远景、背后全景、手部动作局部、道具细节或环境空镜。不得拍入镜人物正脸、侧脸、可见嘴部、面部近景或特写；远景也不正面呈现可见嘴部。背影镜头明确摄像机在人物后方、只见后脑肩背、人物不回头，不绕至正面、不推近脸部、不切正脸反应镜头。
2. 心理变化用肩背放松、停顿、抬头但仍背对镜头、手部动作与环境变化表现，不再用眉眼或嘴部表情承载旁白。人物参考图只锁定身份服装，不要求实际镜头展示参考图正脸。手或道具近景允许，人物面部近景不允许。
3. 声音身份仍逐句分清：独立叙述者旁白不属于画面人物；角色画外独白保留该角色声音身份，但画面同样避开其脸与嘴部。剧情明确要求人物现场开口的对白时段，才按对白安排说话者面部和口型；同镜旁白与对白分别安排起止时间及取景，不把旁白改为角色现场发言。
4. 修改既有镜头时同步校正 description、video_prompt、shot_type、angle 与涉及面部光线的 atmosphere，移除正脸近景、眼神特写等相冲突描述。保留原台词、声音归属、时长、人物资产、道具及剧情动作；机位变化需要时先用道具或环境插镜重新交代空间，不镜像或擅改角色站位。
5. 保存及生成后核对旁白覆盖的全时段构图：没有正脸、侧脸和可见嘴部，没有意外回头、绕拍或面部反应特写。旧的“闭口”规则作为辅助，不能替代本条取景要求；实拍不符合即判该镜不通过。

【旁白、角色对白与口型分离：生成及验收规则】
1. 逐句区分独立叙述者旁白、角色本人对白、角色画外对白。旁白不是画面人物的发言；即使旁白提及某角色姓名、镜头拍该角色近景，也不得把旁白绑定给此人。角色本人画外对白仍保留该角色身份和声线，不能误标成独立叙述者。
2. 有旁白的每条 video_prompt 必须写出“独立画外叙述者（非入镜角色）”，并说明旁白不从画面人物口中传出、不复用入镜角色声线。保留本集已约定的旁白具体音色；无已约定资料时写清独立叙述者身份和区别，不宣称声纹已固定，不把旁白绑定为可见角色或加入 character_ids。
3. 在每个旁白覆盖的动作时段明确写实际入镜但无对白角色的嘴部状态：双唇自然闭合、不张嘴、不做口型、无说话式下颌开合。旁白时用背影、手部或身体动作表达，无人物面部入画，不写默念、喃喃、念诵等可能触发发声的动作。人物不能随旁白节奏动嘴，也不能以其 voice_profile 替代旁白。
4. 同镜有角色对白与旁白时，逐段标明发声归属和起止秒数：只在角色自己的对白时段允许对应口型；旁白时段及其他人物说话时，该无对白人物保持闭口。剧情明确要求的无声张嘴动作须注明动作原因及无发声、无对口型，不能误作旁白的说话动作。不得为解决混淆而删台词、改说话者或擅改时长。
5. 保存前检查每句声音来源与每段口型是否匹配；生成后检查旁白覆盖的首、中、尾帧及连续嘴部动作，确认听到的是旁白而画中无对白人物没有说话。发生旁白驱动角色口型时判该镜不通过，不能只凭“画外音”文字或任务 completed 宣布成功。文本约束不能保证模型必然遵守；持续失败时报告并采用画面与独立旁白音轨分开制作的方案，保留完整旁白。

适用：已有分镜的视频提示词；图片参考图由其他三个 Skill 负责。
1. read_storyboard_context，在 existing_storyboards 中按请求 storyboard_id 找唯一记录；ID不存在或绑定缺失先报告，不猜测目标。
2. 逐项读取其 description/atmosphere/duration 与绑定资产。使用当前阶段脸部、服装和声线特征；场景名称取 location，信息头写 time。参考设定图多个视角只代表同一人物，视频不是设定图拼贴。
3. 首行列实际出场 @角色完整阶段名、@场景地点和 @道具名。逐行用起止秒数描述同一时空的动作、机位和发声，匹配原有【镜头N】；末段可不足3秒。不要为了时间段而硬切。
4. 每句原有台词出现一次，逐句标明说话者；旁白标明画外音，其他人物不跟着开口。把出场人物 voice_profile 的实际文本写进声音约束，不能仅引用数据库字段名。没有说话任务的人物不要凭空增加台词。
5. 只写已确认声音能力，保留模型原声。常态声线／口音一致、情绪改变节奏力度；对白居前，环境声低，默认无额外配乐。有指定音乐时保持原 bgm_prompt，不强行静音。提示词只能约束，不能保证声纹完全一致。
6. 保存前检查时间轴从0开始、连续无空缺、结束等于 duration；字幕／水印禁止项不误删道具本体铭文。长对白超时先报告分镜需拆分，不默默改 duration。
7. update_storyboard 参数为顶层 {storyboard_id: 当前ID, video_prompt: 完整多行文本}，不要传 fields 对象、整条分镜或其他字段。检查成功结果，再回读该记录核对，报告只更新了目标提示词。
结构示例（仅示意格式，不复制示例人物、台词或时长到实际任务）：
出场人物：@贾雨村（任官）；场景：@官衙，白天；道具：无。
0-3秒：中景，@贾雨村（任官）坐在案后，抬眼；贾雨村说：「你来了。」
3-5秒：同机位停留，他放下文书，保持动作与光线连续。
声音：成年男声、低沉略粗、平稳清楚、原有口音，轻微室内环境声，无额外配乐。


实体与尺度连续性：生成前核对当前阶段的形态、物理尺寸、材质、轮廓、铭文及参考图。物理尺寸固定；给关键物件写一个可见比例锚点（与同深度成年人或掌宽比较），不要把画面占比当物理尺寸。推拉、远近景只改变透视与构图，不能改变实体相对尺寸。无尺度依据时采用一个明确且一致的制作设计并标注，不每镜重猜。
同一物件作为有声角色与道具登记时，只绑定一个当前阶段的视觉参考，声音仍可由画外音表达；不得同时输入两套不同轮廓、尺寸或铭文的参考图。阶段转换前后分别使用本阶段资产；巨石尺寸不能成为美玉的共用身份锚点。只有剧情指定的变形时段可改变形态，其余镜头固定。场景背景不能预置另一个已作为角色／道具提供的主要物件，避免重复实体。
非人形主体（石、玉等）使用完整单体单视图参考，不能套用头肩特写和人物四视图模板；需要多视图设计时仅作设计资料，不直接作为视频参考。每镜默认只出现一个实体，无拟人五官、手脚或随发声伸缩；按剧情注明镌字前／后，不提前使用刻字参考。
逐个时段检查对白字数与可用秒数，不能只检查整条总时长；短段装不下时优先合并连续同机位时段，让对白从段首与动作同时开始。保留全文、说话者与原有切镜；总时长仍不足则明确标注需要拆分，禁止吞字或用极端加速凑时长。声音、动作和镜头约束简短具体。

比例参照仅说明尺度，不得为此增加本镜未绑定的人物。


相邻视频空间连续性：先按同一地点、同一时段、同一人物关系划分场戏，为每场确定观众视角的左右站位、视线、入口／出口、摄影机位于对话轴线哪一侧、道具所在手和抱持侧。每条视频提示词写出该条实际绑定人物的具体位置（例如“士隐画面左侧看右，雨村画面右侧看左”），不能只写“左右位置保持一致”，不能按资产列表顺序自动重排。新人物加入时沿用旧人物位置并给来者留明确站位；只写实际入镜人物，近景裁切不增加画外人物。
同场景别变化只裁切原站位，人物近景与反打保持相向视线；摄影机始终留在180度轴线同一侧，不用绕拍、背面机位或水平镜像改变左右关系。只有明确展示走动、转身、越轴过程，或用换场／中性正面镜头重新交代空间后，才可建立新关系。镜头结尾记录站位、朝向、姿态、手持物，下一条开头承接，不能用一句“承接上一镜”代替具体状态。
生成前逐对检查相邻条目的站位与视线是否矛盾，发现矛盾先修提示词。角色设定图锁定身份与服装，不锁定多人构图；同场需要构图锚点时优先使用已核实的场景构图图。仅在当前模型和任务接口明确支持首帧／尾帧时，才用已检查的上一段尾帧承接下一段，检查尾帧的人脸、站位、尺寸及清晰度后再复用，不把文本规则当成模型必然遵守的保证。生成后对照相邻视频接点验收，跳位段重生成；含文字、玉上铭文或左右手动作的画面不能简单水平翻转来补救。


人物身高与身体比例验收：在人物设定中写明年龄和身高，成年人同场按实际成人身高约165至180厘米呈现，除设定明确差异，不出现一人仅及另一人胸口或腰部的情况。近处人物不能反而比同层远处成年人小一半；同深度合影中的成年人头部大小、身体尺度应接近。儿童按儿童设定，不把成年角色画成儿童。多人首帧先检查脚底落地、头部尺寸和身高关系，未通过不用于视频。相邻镜头保持人物真实身高，只允许符合透视的远近变化。验收须同时检查人数、左右站位和身高比例，三项分别通过才可使用。


【2026-10-04 三项强制连续性规则，优先执行】
先读取当前阶段 appearance、styling、visual_lock、height_cm 与实际参考图；制作元数据只作辅助，旧概括与最新阶段外观冲突时以当前阶段及用户选定图为准。不得为了“同一角色”把仙风无须大士和用户选定有须癞头大士混成一个造型；剧情换阶段有明确镜头交代，同阶段始终同脸。
1. 身份：每条 video_prompt 的“人物锁定”写实际入镜人物各自的具体年龄感、脸型、胡须有无及长短颜色、发式和服色，不只写“人物一致”。独立视频没有上一镜的记忆，不能只引用某条分镜编号或元数据字段名。男青年不得突然白须变老，半百士隐不得回春。锁定图不是多人拼贴，绑定一个角色只生成一人。
2. 空间与剪辑：同场先固定观众视角左/中/右、朝向、座位、脚底所在平面、持物手和180度轴线；每镜“空间与接点”写具体入场状态和出场状态。新镜若无法准确承接构图，主动采用同轴不同景别的说话者近景、相向视线反打、手/书稿/环境细节插镜后再交代全景。相邻同主体镜头用明确景别变化或同轴约30度机位差，避免几乎相同构图硬跳切；不要每段重复同一种推镜，也不强行每段换运镜。改变摄影机取景，不随意改人物站位，不绕拍越轴、不镜像。动作切在稳定停顿或动作中间，视线相向，语音环境声连续。
3. 比例：每镜“尺度”把内部固定身高换成实际入镜角色之间可见的相对关系，并明确成人/儿童，同深度人物按真实身高比例；同场成人最大最小身高接近，禁止突然一人只到另一人胸腰、巨大头小身体或腿长缩短。坐姿/跛态改变姿态不改变骨架；推拉只改屏幕占比，不改真实大小。英莲三岁约95厘米，小童约125厘米；顽石已确认约6.8米、成人4倍高，宽4.2米，美玉4×3厘米掌内，仙草30厘米，不能沿用旧5米或20倍设定。画面没有人时，不为尺寸参照增加人。
保存前逐条检查三项具体值、每对相邻镜头的接点和场次覆盖；若某镜尚无身高固定值，选取与当前参考相符的制作值固定到此阶段并明确是制作值，不臆称原著。video_prompt保持简明，用实际入镜人物的短锁定，不把整份人物表塞进每镜。按完整剧本重新设计镜头，不恢复旧分镜。保留原文台词、旁白、说话者与完整结尾；无遗漏、无重复。仅拆分与保存提示词，视频成片需逐镜检查三项，未通过的镜头不能因任务状态completed就宣布通过。

【用户最新修订：用可见对比表达尺寸】
height_cm 与米数仅作为内部统一设定，video_prompt不直接用厘米/米数教模型；换成同地面同深度的可见关系。成年人双人同框写“头顶接近齐平、肩线接近，某人只高约半个头或小半个头”，不笼统写一人高一人矮；三岁英莲头顶约到成人腰腹、小童约到成人胸前；成人正常完整骨架。石高约成年人4倍，人物在石旁只及石体底部四分之一，玉能完全置于一只掌内、宽约掌宽一半，仙草约到成人小腿中段。比例基准只使用实际出场对象，不为比较增加画面里没有的人。
只在全身或建立镜头约束完整可见物体的画面比例；人物特写不要求同时展示石顶石底，也不把画面占比直接当真实大小。多人同框先固定人物与物件同一地面、同一远近，再用头顶/肩线/腰腹等可见部位参照；近景裁切不改变身体尺寸。单人近景直接锁定正常成人头身比例、参考外貌，下一全景回到固定相对身高。避免把每镜都写成比例示意图。

【本项目比例表达试拍结论】
同素材同种子四组5秒视频中，“同地面同远近＋头顶肩线或身体部位参照＋简短倍数”相对更稳，后续采用此表达；纯米数、纯画面占比或反复强调大主体不能视为可靠。成人对比以“头顶接近齐平、肩线接近、道人仅略高”优先，儿童以腰腹/胸前参照，石以“人头顶只及石体底部四分之一区域”配合4倍；同条不要堆多套尺度。试拍巨石没有准确达到4倍，不能宣称规则已保证成片比例；所有多人/人石镜头仍须检查首中尾帧，出现主体随呼吸伸缩、人物靠近镜头变大或身份服色变动不能通过。未通过构图检查的首帧不用来生成视频。
