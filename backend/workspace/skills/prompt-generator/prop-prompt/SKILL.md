---
name: prop-prompt
description: 原著依据与完整白底单品道具
---

读取物件名称与外观；剧情关键物件先核实原文资料和时代，材料、色彩、形状、磨损与雕刻逐项描述。通灵宝玉等已核实本体铭文必须保留，不能误当水印删除；文字生成可能不准确，生产时另行校字，不声称生图必定正确。
白底孤立单品，3/4标准静物视角；纸张平铺俯视。主体完整、比例稳定、边缘不裁切，光线均匀，阴影轻。没有人物、手部、场景、无关包装、展示架、字幕水印。道具本体图案及文字除外。项目风格由工具注入，不追加摄影／电影质感等冲突风格；调用 save_prop_final_prompt 保存。

执行检查：先用 read_props 按请求的 prop_id 找到记录，只处理指定资产；未找到则报告，不猜ID。使用原始外观字段重写，不复制已注入风格的 final_prompt。最终文本突出具体材质、形状和辨识细节，避免重复形容词。用 save_prop_final_prompt 的顶层 {prop_id: 当前ID, prompt: 单段正文} 保存；检查 saved:true 和返回ID。保存结果可含工具自动加入的风格，不将其再次作为 prompt 原文重复保存。若资料与已确认设计冲突，说明差异而非擅自覆盖其他资产。


实体与尺度连续性：生成前核对当前阶段的形态、物理尺寸、材质、轮廓、铭文及参考图。物理尺寸固定；给关键物件写一个可见比例锚点（与同深度成年人或掌宽比较），不要把画面占比当物理尺寸。推拉、远近景只改变透视与构图，不能改变实体相对尺寸。无尺度依据时采用一个明确且一致的制作设计并标注，不每镜重猜。
同一物件作为有声角色与道具登记时，只绑定一个当前阶段的视觉参考，声音仍可由画外音表达；不得同时输入两套不同轮廓、尺寸或铭文的参考图。阶段转换前后分别使用本阶段资产；巨石尺寸不能成为美玉的共用身份锚点。只有剧情指定的变形时段可改变形态，其余镜头固定。场景背景不能预置另一个已作为角色／道具提供的主要物件，避免重复实体。
非人形主体（石、玉等）使用完整单体单视图参考，不能套用头肩特写和人物四视图模板；需要多视图设计时仅作设计资料，不直接作为视频参考。每镜默认只出现一个实体，无拟人五官、手脚或随发声伸缩；按剧情注明镌字前／后，不提前使用刻字参考。
逐个时段检查对白字数与可用秒数，不能只检查整条总时长；短段装不下时优先合并连续同机位时段，让对白从段首与动作同时开始。保留全文、说话者与原有切镜；总时长仍不足则明确标注需要拆分，禁止吞字或用极端加速凑时长。声音、动作和镜头约束简短具体。
