---

先读取角色当前阶段 appearance、styling 与 identity_anchor，逐项落实身份标记、脸部比例、眉眼、发际线、体态与服装材质。年龄按当前阶段，不任意年轻化、美颜化；原著明确的标记不可删，如英莲／香菱的眉心胭脂痣。存在多个阶段时复用人物身份特征，只变该阶段的年龄感、服装和长期身体状态。
仅人形角色的设计资料：构图为左侧清晰正面头肩面部特写，右侧横向并排的正面／严格90度侧面／严格正背面三张等高全身视图；只有同一人物的一张面部特写加全身三视图设定展示，不是多名不同人物。视图脸、发型、衣服、配饰一致；全身完整不裁脚，白底、柔和均匀光线、中性姿态。辨识细节优先于空泛的精美词。
参考图不含戏剧动作、夸张表情、其他人物、字幕、标签和水印。项目风格由保存工具自动注入，不追加电影质感或与风格冲突词；用 save_character_final_prompt 实际保存。

执行检查：先用 read_characters 按请求的 character_id 找到记录，只处理指定资产；未找到则报告，不猜ID。使用原始外观字段重写，不复制已注入风格的 final_prompt。最终文本突出具体材质、形状和辨识细节，避免重复形容词。用 save_character_final_prompt 的顶层 {character_id: 当前ID, prompt: 单段正文} 保存；检查 saved:true 和返回ID。保存结果可含工具自动加入的风格，不将其再次作为 prompt 原文重复保存。若资料与已确认设计冲突，说明差异而非擅自覆盖其他资产。


实体与尺度连续性：生成前核对当前阶段的形态、物理尺寸、材质、轮廓、铭文及参考图。物理尺寸固定；给关键物件写一个可见比例锚点（与同深度成年人或掌宽比较），不要把画面占比当物理尺寸。推拉、远近景只改变透视与构图，不能改变实体相对尺寸。无尺度依据时采用一个明确且一致的制作设计并标注，不每镜重猜。
同一物件作为有声角色与道具登记时，只绑定一个当前阶段的视觉参考，声音仍可由画外音表达；不得同时输入两套不同轮廓、尺寸或铭文的参考图。阶段转换前后分别使用本阶段资产；巨石尺寸不能成为美玉的共用身份锚点。只有剧情指定的变形时段可改变形态，其余镜头固定。场景背景不能预置另一个已作为角色／道具提供的主要物件，避免重复实体。
非人形主体（石、玉等）使用完整单体单视图参考，不能套用头肩特写和人物四视图模板；需要多视图设计时仅作设计资料，不直接作为视频参考。每镜默认只出现一个实体，无拟人五官、手脚或随发声伸缩；按剧情注明镌字前／后，不提前使用刻字参考。
逐个时段检查对白字数与可用秒数，不能只检查整条总时长；短段装不下时优先合并连续同机位时段，让对白从段首与动作同时开始。保留全文、说话者与原有切镜；总时长仍不足则明确标注需要拆分，禁止吞字或用极端加速凑时长。声音、动作和镜头约束简短具体。

本项目角色三视图要求：三个角度头顶和脚底齐平，成年正常头身比，儿童按实际年龄。仙草等植物设计必须呈自然落地状态：根系全部埋于小块地面土壤下，地表只见茎叶花苞，不画透明土壤截面、拔根、悬空裸根。角色三视图是生成镜头合成画面的设计参考，不直接当作视频首帧。

原著优先：明确身份标记、身体特征、年龄、动作、衣着优先逐项核对原文。不得把相邻角色描写交叉套用，如第一回“那僧则癞头跣脚，那道则跛足蓬头”，癞头与跣脚用于僧，跛足与蓬头用于道。原文未交代的发量、脸型、颜色等只作必要视觉补足，不冒充原著明确设定，不擅自增加戒疤、首饰或剧情。

身份、年龄与尺度约束：不同人物先分别建立脸型、下颌、颧骨、眉眼、鼻、嘴等具体差异；不把同一张人物图当所有人的风格参考，避免复制五官。同一人物跨阶段保留同一骨相，服装变化不能代替身份区分。原著有年龄则落实到面部皮肤、眼袋、皱纹、须发与体态，如甄士隐年已半百；无数字年龄时依据亲属辈分作必要制作补足并注明，如封肃为甄士隐岳丈。顽石未入红尘与刻字后是同一实体，按用户最新确认竖立石头、石高约同深度成人4倍，保持上窄下宽和固定体量。用户要求的全身尺度参照图可有一个完整普通成人，人约石高四分之一；参照者不是剧情人物，正式镜头不得复制。

已确认例外：用户选定茫茫大士（癞头疯癫）使用瘦脸参考 honglou-gpt-characters-22-v3.png；仙风道骨形态保持现有宽圆脸。这是用户确认的幻形设计，不应用跨阶段统一骨相规则强制改回圆脸。

用户已确认的最新顽石制作比例：竖立单体，上窄下宽，约四倍成人高；无字与刻字形态同轮廓同尺度。这项视觉指示覆盖此前根据原文设的20倍人高或宽扁横卧形态。跛足道人的右膝、右脚及偏侧承重应可见，袍摆不能遮住全部脚踝；行走左稳右拖，不画普通对称站姿或平稳步态。
