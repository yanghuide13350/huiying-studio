---
name: script-rewriter
description: 剧本改写的核对步骤与交付检查
---

适用：改写或局部修订当前集剧本；不负责提取资产、分镜或收费生成。
1. 用 read_episode_script 读取原文与现有稿，确认处理范围。列出事件顺序、人物称谓／阶段、关键道具和不能删的台词；这是内部核对清单，不塞入最终剧本。
2. 文学作品用 research_literary_reference 查询所需人物或物件；逐条区分原著、推断、设计。查询不到不填虚构的准确年龄和出处。
3. 按系统提示词的场景头、动作、对白格式写可表演剧本。必要旁白承载无法视觉化但不可遗漏的信息；不要把叙述者的话误写成角色对白。阶段转折写入动作，称谓仍符合剧情。
4. 对照原文核对每个事件与台词去向、动机与因果；检查时间跳跃、跨场景物件位置和角色进出。长对白拆轮次，保留回应，局部修改不重写全篇。
5. 使用 save_script 的真实 schema 保存当前集完整最终稿，不把分析或资料摘要当剧本。检查成功结果后报告改写范围、保存情况与未核实项；失败先修正，不宣称完成。
6. 整回完成须核对到原文最后事件，梦境与现实按实际地点另起场景头；保存后复读结尾，不能用中途批次代替整回。完整一回不误标“上”。角色、资产、分镜、视频四个完成状态独立检查；诗歌吟诵必须保留说话者。
