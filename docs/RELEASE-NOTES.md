慧影工坊：AI 剧本、素材与视频制作工作台。

下载请选择自己的系统：
- Apple 芯片 Mac（M1/M2/M3/M4 等）：文件名带 `arm64` 的 `.dmg`。
- Intel Mac：带 `x64` 的 `.dmg`。
- Windows 64 位：`setup` 安装程序 `.exe`。

Mac 打开 DMG 后将「慧影工坊」拖入「应用程序」。Windows 双击安装程序，按提示安装。ZIP 供升级或手动解压使用，普通用户优先选择 DMG/EXE。

首次启动在设置中配置自己的模型服务与 API 密钥，软件不附带模型额度。

此版本尚未配置 Apple Developer 公证与 Windows 代码签名，系统可能显示安全提示；尚未完成 Windows 实机和 Intel Mac 实机的完整操作验收。

从 HuobaoDrama 升级的 macOS 用户会继续使用原有本地数据目录；仅移走旧版程序，不要删除 Application Support/HuobaoDrama 项目数据。
